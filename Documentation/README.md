# Documentation

This folder contains the two ITU-T recommendations the library conforms to:

- **`T-REC-Q.23-198811-I!!PDF-E.pdf`** — [ITU-T Q.23](https://www.itu.int/rec/T-REC-Q.23/) (November 1988). *Technical features of push-button telephone sets.* Defines the DTMF frequency pairs for each key.
- **`T-REC-Q.24-198811-I!!PDF-E.pdf`** — [ITU-T Q.24](https://www.itu.int/rec/T-REC-Q.24/) (November 1988). *Multi-frequency push-button signal reception.* Defines detector behaviour, including the Standard_Twist tolerance band (+4 dB / −8 dB).

Copies are kept here so the library can be read and understood offline. The requirements doc ([`docs/requirements.md`](../docs/requirements.md)) and the design doc ([`docs/design.md`](../docs/design.md)) both cite them.
